Project Description
THE SENTIENT CURSOR is a completely unnecessary document-reading experiment where the document actively tries to escape from the user.
The user has 30 seconds to catch the READ DOCUMENT button while the system tracks their mouse behaviour, increases the document's rage, creates fake button clones, and judges their performance.

The Problem (that doesn't exist)
People sometimes struggle to read important documents.
Our solution is to create a much bigger problem: a document that refuses to let you read it.

The Solution (that nobody asked for)
We created a fake interactive document whose READ DOCUMENT button runs away whenever the user gets close to it.
As the user keeps chasing it:
The document becomes increasingly difficult.
Fake READ buttons appear.
The system analyses mouse movement.
Document rage increases.
Respect decreases.
The threat level changes.
The document changes pages and insults the user.
Sounds react to the user's actions.
Eventually, the user either catches the button or loses to a piece of HTML.
At the end, the user receives an extremely official “CERTIFICATE OF NOTHING ACHIEVED.”
